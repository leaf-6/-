## 豆瓣图书爬虫（支持断点续爬）  --- 仅供学习使用

### 爬虫初衷：
---

>  不仅仅是大众推荐的热销书;
> > 还有从豆瓣图书中，从海量的图书找到评分高、评价人数多的、却非大家所熟知的好书;
> > > 从书海中偶遇适合自己阅读的书。  
  

---
#### 各文件作用说明：

- `main.py` -- 程序入口
- `config.py` -- 配置（关键词、USER_AGENT等）
- `spider.py` -- 爬虫调度
- `parser.py` -- 表页、详情页解析
- `progress.py` -- 断点进度管理
- `excel.py` -- Excel 文件导出
- `login_once.py` -- 生成登录态
- `requirements.txt` -- 依赖





#### 功能特点：
1. 多关键词爬取
2. 断点续爬：程序中断后可以从断点恢复
3. 详情页风控感知（自动暂停，避免封号）
4. 功能拆分
5. 根据豆瓣评分从高到低排序


#### 使用步骤：
1. 安装依赖：
   pip install -r requirements.txt
2. 首次运行生成登录态
3. 关键词配置在 `config.py` 文件设置。

###  注意事项
- 本项目仅用于学习与技术研究，请合理设置爬取间隔，避免对豆瓣服务器造成压力。
- 本地断点文件 `douban_progress.json` 与登录态 `douban_state.json` 均为私有运行数据，已被忽略，请勿强制提交。
